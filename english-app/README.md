# Chunk Daily

90日で「言いたいことがすぐ英語で出る」ようにするための練習アプリ。claude.ai の Artifact として公開しています。

- 今日:毎朝届く10パターン(音声つき、英語をかくすモードあり)を3回まねして音読
- テスト:日本語から6秒以内に英語を言う瞬間英作文。間隔反復で、苦手なパターンは翌日にまた出る
- 会話:Claudeが今日のパターンと苦手パターンを使わせる質問をし、答えるたびに添削と「こう言える」を返す(5往復でクリア)
- 記録:90日カレンダー、連続達成日数、未完了の日、苦手パターン、覚えたパターン一覧

毎朝6:47(日本時間)に定期タスクがその日の10パターンを作って通知し、21:13に未完了のメニューがあれば通知します。

データは Artifact のデータベースに保存:`days/<日付>`、`progress/<日付>`、`cards/<パターンID>`、`talks/<日付>`。

## 習得度と難易度の自動調整

- パターンの状態:習得(テストで4段階以上+会話で1回以上使えた)/使えていない(テストは言えるが会話では未使用)/練習中/苦手
- 会話で使えたパターンは自動で記録(`cards/<id>.usedCount`)。「使えていない」パターンは会話の質問で優先して出る
- 毎朝の配信で直近7日の正答率・会話での使用率を見てレベル(Lv1〜5、`meta/level`)を上げ下げ。下がった日は新しいパターン7個+苦手パターンのやさしい言い換え3個になる
- 毎週日曜9:23に週間レポート(`reports/<日付>`)を作成して通知。記録タブに表示
