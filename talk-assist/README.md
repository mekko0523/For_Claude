# ハヤサポEnglish（英会話サポート PWA）

iPhone のマイクで相手の英語を聞き取って画面に出し、**そのまま読み上げれば会話が続く英語の返事・質問の候補**を表示するアプリです。
英語が話せなくても、候補を読むだけで会話ができることを目指しています。

- 音声認識：Soniox（リアルタイム、英語）
- 相手の発言の和訳：Soniox のリアルタイム翻訳（話している最中から出ます）
- 返事の候補：Claude。⚙️ 設定の「候補を作るAI」で選べます
  - **Haiku 5.5**（標準）：速くて安い（考える処理なしで動かします）
  - **Opus 5.5**：質は高いが、候補が出るまで時間がかかり、料金は約40倍
- ホスティング：Cloudflare Workers（画面と API を1つの Worker で配信）

## 使い方

1. アプリの URL を Safari で開き、共有ボタンから「ホーム画面に追加」します。
2. 初回は ⚙️ 設定で**合言葉**を入れます。👤 の**自己紹介メモ**（名前、仕事など）を一度書いておくと、自分に合った返事が出ます。
   画面上部のボタンで**場面**（英会話教室・社内会議・商談・旅行など）を選べます。
3. 「▶ 開始」を押して、相手に話してもらいます。
4. 相手が話し終わると、英文（と和訳）の下に候補が4つほど出ます。好きなものを読み上げてください。
   「返答候補」の横に、最初の候補が出るまでの秒数と使ったAI（例：`0.9秒（Haiku）`）が出ます。
   - **候補を読み上げる**と、アプリが自分の発言だと判断して会話に記録し、相手の返事を待ちます。
   - **候補をタップ**しても記録できます。聞き取りがうまくいかないときに便利です。
   - 言いたいことがあるときは、一番下の欄に入れて ➤ を押します。**「釣り」「来週」「price」のような単語だけでも**、会話の流れからどう使いたいかを考えて英文の候補を作ります。欄に入れたままにしておくと、相手が次に話したときの候補にも使われます。候補のどれかで返事をすると、欄は空になります。
   - 「🔄 別の候補」で作り直せます。
   - 候補にない英語を自分で話すときは左下の「🙋 自分」を押します。押している間の声は自分の発言になります。
5. 聞き分けを間違えたときは、会話の吹き出しをタップすると直せます（相手→自分に直す／自分の発言を消す）。
6. 5分間何も聞こえないと自動で停止します。🗒️ を押すと新しい会話を始められます（前の会話は記録に残ります）。

### 場面：英会話教室・社内会議
画面上部の**英会話教室**を選ぶと、レッスン向けの候補になります。
- 先生の質問に、少しだけ中身のある答え（理由や例を1つ添える）を出します
- 先生に直されたときは、直された文を言い直す候補を入れます
- 難しい単語が出たときは「What does ○○ mean?」のような質問を入れます

**社内会議**を選ぶと、丁寧で簡潔なビジネス英語で、賛成・反対、意見や進み具合の報告、確認の質問、決定事項や期限の確認といった候補を出します。

### 使用量（会話ごと）
画面上部の状態の横に、今の会話で使った **Claude と Soniox の合計金額（ドル）** の概算（例：`$0.0123`）が出ます。
📜 で会話を開くと、内訳が見られます。
- **Claude**：呼び出した回数、入力・出力のトークン数、料金（Worker が API の応答に含まれる使用量から計算）
- **Soniox**：聞き取った時間と料金（送った音声の長さ × 1時間あたり $0.12 で計算）

どちらも概算です。正確な請求額は Claude Console と Soniox の管理画面で確認してください。
相手の発言が続いて途中で取り消した候補作りの分は数えていないため、実際より少し少なく出ることがあります。

### 会話の記録・コピー
📜 を押すと、これまでの会話の一覧が出ます。開くと全文（英語と和訳）を読めて、**📋 コピー**でメモアプリや LINE などに貼り付けられます。
「この会話を続ける」で前の会話の続きから再開でき、要らない会話は削除できます（端末に最大60件まで残ります）。

### 👤 自己紹介メモ・覚えていること
👤 を押すと、**自己紹介メモ**と**覚えていること**が出ます。どちらも、項目をタップしたときだけ中身が開きます。
- 自己紹介メモは一度書けばそのまま使われます。書き直すと自動で保存されます
- 覚えていることは、会話を停止したときや新しい会話を始めたときに、Claude が**自分が話した事実・相手のこと・これまでの話題・続きの話・英語の学習メモ**をまとめて追記・整理します。次の会話からは、以前の発言と食い違わない返事や、前回の続きの話題を振る候補を出します
- どちらも直接書き直せます。「今の会話から更新」で、覚えていることにすぐ反映できます
- この2つは**サーバー（Cloudflare KV）に保存**されるので、アプリを更新しても、Safari とホーム画面のアプリのどちらから開いても消えません（合言葉だけは端末ごとに入力が必要です）
- 会話の記録（📜）は端末の中にだけ保存されます

> iPhone では、Safari が裏に回ったり画面がロックされたりするとマイクが止まります。会話中はアプリを開いたままにしてください（使用中は画面が消えないようにしています）。

## 構成

```
[iPhone Safari / PWA]  ── 同じオリジン ──  [Cloudflare Worker: talk-assist]
   │                                         ├─ web/ の静的ファイル(画面)
   │ ① POST /api/soniox-key                  ├─ Soniox の一時キーを発行(60秒・1回限り)
   │ ② WebSocket で音声を直接送る ─────────→ [Soniox stt-rt]
   │ ③ POST /api/suggest(会話の履歴)        └─ Claude に候補を作らせ、1行1候補で流す
   ▼
 相手の発言が終わる(Soniox の <end>)→ 自分の発言か判定 → 相手なら候補を作る
```

| パス | 内容 |
|---|---|
| `web/index.html`, `style.css`, `app.js` | 画面と処理（音声認識、発言の区切り、自分の発言の判定、候補の表示） |
| `web/manifest.json`, `sw.js`, `icons/` | PWA 用 |
| `worker/src/index.js` | Worker（画面の配信、Soniox の一時キー、Claude で候補を作る、「覚えていること」の更新、メモの保存） |
| `worker/wrangler.toml` | Worker の設定。モデルなどはここの `[vars]` で変えられます |
| `../.github/workflows/deploy-talk-assist.yml` | デフォルトブランチへの push で自動デプロイ |

API キーはすべて Worker の Secret に入れ、ブラウザには渡しません。API は合言葉がないと使えず、画面と同じオリジンからの呼び出しだけを受け付けます。

## 必要な GitHub Secrets

リポジトリの **Settings → Secrets and variables → Actions** で登録します（ハヤメモと共通のものは登録済みです）。

| Secret 名 | 内容 | 状態 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude の API キー（https://platform.claude.com で作成） | **新しく登録が必要** |
| `SONIOX_API_KEY` | Soniox の API キー | ハヤメモで登録済みなら不要 |
| `APP_PASSPHRASE` | アプリで入力する合言葉 | ハヤメモと共通 |
| `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID` | Cloudflare | ハヤメモと共通 |

## デプロイ

1. 上の Secret を登録します。
2. デフォルトブランチに `talk-assist/` の変更を push するか、**Actions → 「Deploy talk-assist (Cloudflare Worker)」→ Run workflow** を押します。
   自己紹介メモ・覚えていることの保存先（KV「talk-assist-store」）は、初回のデプロイで自動で作られます。
3. 完了すると、ジョブの Summary に**アプリの URL**（`https://talk-assist.<サブドメイン>.workers.dev`）が出ます。

## 調整できるところ

- `worker/wrangler.toml`
  - `CLAUDE_MODEL`：画面で選ばなかったときの既定のモデル（`claude-haiku-5-5`）
  - `CLAUDE_EFFORT`：考える量（`low` / `medium` / `high`）。上げると質は上がり、候補が出るまでの時間は長くなります
  - `SONIOX_MODEL`：音声認識のモデル
- 設定画面の「話し終わりの判定」：早くすると候補が早く出ますが、相手の話が途中で区切られやすくなります。
- `web/app.js` の先頭の定数：自動停止までの時間、自分の発言とみなす一致度など

## ローカルで動かす

```bash
cd talk-assist/worker
npm install
cp .dev.vars.example .dev.vars   # 値を入れる(コミットしない)
npx wrangler dev                 # http://localhost:8787
```

## 料金の目安

- Soniox：聞き取っている時間に応じて課金されます（ハヤメモと同じ単価で 1時間あたり約 $0.12）。
- Claude：相手が1回話すたびに1回、会話の終わりに「覚えていること」の更新で1回呼び出します。「覚えていること」が長いほど1回あたりの料金が少し増えます。会話の量やモデルで変わるので、Claude Console で使用量を確認してください。
